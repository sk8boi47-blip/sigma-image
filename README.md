# Sigma Image

A simple GitHub Pages site that displays the supplied image.

## Custom domain

The site is configured for `sigma.oliworx.dev`. In Namecheap, add a CNAME record with host `sigma` pointing to `sk8boi47-blip.github.io`. In this repository's Settings → Pages, select GitHub Actions as the source and enter `sigma.oliworx.dev` as the custom domain.
